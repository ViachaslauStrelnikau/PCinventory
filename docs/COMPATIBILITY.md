# Совместимость Windows

## Матрица PoC

| Целевая Windows | x86 | x64 |
|---|---|---|
| Windows 7 SP1 | NOT TESTED | NOT TESTED |
| Windows 8 | NOT TESTED | NOT TESTED |
| Windows 8.1 | NOT TESTED | NOT TESTED |
| Windows 10 | NOT TESTED | NOT TESTED |
| Windows 11 | Вне матрицы | Частичная проверка JAR и JVM |

На рабочей станции Windows 11 Pro (build 26300) Maven 3.9.11 собрал агент с JDK 8u501 x64. Класс точки входа имеет bytecode 52. Один и тот же JAR с `--probe` запустился на Java 8u501 x64 и Java 8u221 x86. На Java 8u221 x86 проверены обычный запуск, ручное чтение, сохранение инвентарного номера с ведущими нулями и демонстрационный режим с карточками ОЗУ и дисками. В окне 820 × 700 обе кнопки видимы, регистрация заблокирована. Эти локальные runtime использованы только для проверки каркаса.

Java 8u221 x86 сообщает `Windows 10` в `os.name` на этой станции. Поле `os.arch` показывает архитектуру JVM. Источник семейства, сборки и архитектуры ОС предстоит проверить отдельно.

Локальный Emulator Suite проверен с Firebase CLI 15.37.0 и JDK 22. Маршрут Hosting вернул страницу SPA. Auth создал синтетического пользователя, которому Firestore запретил чтение и запись. Эта проверка не относится к публичному TLS из агента.

Оставшиеся проверки этапа 0 — WMI и OSHI/JNA, полный объём RAM в WOW64, GPU и VRAM, физические диски, режимы сети, Swing на целевых разрешениях и DPI, пробная упаковка и запуск из read-only UNC, TLS и синтетическая запись в разрешённом dev Firebase. Версии и лицензии распространяемых компонентов будут зафиксированы после PoC.
